

## 🐛 Common Issues

### Issue 1: CORS Errors
**Solution**: Update `CORS_ORIGINS` in backend to match frontend URL

### Issue 2: Database Connection
**Solution**: Verify `DATABASE_URL` is set in backend variables

### Issue 3: Frontend Can't Reach Backend
**Solution**: Check `VITE_API_BASE_URL` is correct (use HTTPS!)

### Issue 4: PostGIS Functions Fail
**Solution**: Verify extensions: `CREATE EXTENSION postgis; CREATE EXTENSION postgis_sfcgal;`

### Issue 5: Build Fails
**Solution**: Check logs for specific error, verify Dockerfiles are correct

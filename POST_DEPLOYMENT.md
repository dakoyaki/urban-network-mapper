## 🔧 Configuration Needed

### Backend Environment Variables

Verify these are set in Railway Dashboard → Backend → Variables:

| Variable | Required | Example |
|----------|----------|---------|
| `DATABASE_URL` | ✅ Yes | Auto-generated by Railway |
| `SECRET_KEY` | ✅ Yes | Random 32-char string |
| `FLASK_ENV` | ✅ Yes | `production` |
| `CORS_ORIGINS` | ✅ Yes | Frontend URL or `*` |
| `DEFAULT_PROJECT_EPSG` | ✅ Yes | `3857` |

**Generate SECRET_KEY:**
```bash
python -c "import secrets; print(secrets.token_hex(32))"
```

### Frontend Environment Variables

For frontend service (when deployed):

| Variable | Required | Example |
|----------|----------|---------|
| `VITE_API_BASE_URL` | ✅ Yes | `https://backend-url.up.railway.app/api` |
| `VITE_VWORLD_API_KEY` | ⚠️ Optional | Your V-World API key |

⚠️ **Important**: URL must use HTTPS and include `/api` at the end!

### Step 1: Deploy Frontend (if not done)

1. In Railway Dashboard → **New Service** → **GitHub Repo**

## 🐛 Troubleshooting

### Backend Returns 500 Errors

**Check logs:**
```
Railway → Backend → Logs → Look for Python traceback
```

**Common causes:**
- Missing environment variables
- Database not connected
- PostGIS extensions not enabled

**Fix:**
1. Check all required variables are set
2. Verify database service is active
3. Enable PostGIS extensions manually

### Frontend Can't Connect to Backend

**Symptoms:**
```
Failed to fetch
CORS policy blocked
```

**Check:**
1. `VITE_API_BASE_URL` is correct (HTTPS, includes /api)
2. `CORS_ORIGINS` in backend matches frontend URL exactly
3. Backend is actually running (check logs)

**Fix:**
1. Update frontend variable
2. Update backend CORS
3. Restart both services

### Database Connection Fails

**Symptoms:**
```
psycopg2.OperationalError
Connection refused
```

**Check:**
1. `DATABASE_URL` is set in backend variables
2. PostgreSQL service is active
3. Network connectivity between services

**Fix:**
1. Re-link services if needed
2. Regenerate `DATABASE_URL`
3. Check Railway status page

### Export GeoPackage Returns Empty File

**Check:**
1. Do you have data? (polygons/edges/nodes)
2. Check backend logs for export errors
3. GeoPandas installed? (should be in build logs)

**Fix:**
1. Draw some features first
2. Check logs for specific errors
3. Rebuild if dependencies missing
